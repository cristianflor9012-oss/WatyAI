# 🤖 WatyAI - Local Terminal AI Assistant

**WatyAI** es un asistente de Inteligencia Artificial para la terminal de comandos, optimizado para chips **Apple Silicon** mediante la arquitectura de memoria unificada de macOS. 

El motor está impulsado por **Qwen 2.5 7B Instruct (3-bit)** con la librería `mlx-lm`, e integra capacidad de búsqueda web en tiempo real sin depender de servicios externos pagados.

Desarrollado para la ecosistema de **ExeLux**.

---

## ⚡ Características Principales

* 🧠 **Ejecución 100% Local**: Funciona directamente en Apple Silicon utilizando la memoria unificada.
* 🌐 **Búsqueda Web Automática**: Conexión a internet mediante `ddgs` para respuestas actualizadas.
* ⚡ **Streaming en Vivo**: Generación de texto token por token a alta velocidad.
* 💻 **Optimizado para Código**: Formateo limpio en Markdown para múltiples lenguajes de programación.
* 🛡️ **Prevención de Bucles**: Configuración ajustada de muestreo para evitar repeticiones.
